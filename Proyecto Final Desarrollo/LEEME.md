# Instrucciones

Usa `README.md` para abrir y ejecutar la versión refactorizada de la solución. La guía anterior correspondía a la versión inicial, que tenía consultas y lógica directamente en el code-behind.

`IniciarSitio.cmd` abre la solución en Visual Studio. La ejecución necesita Visual Studio con el componente Web Forms, .NET Framework 4.8.1 y una instancia SQL Server configurada en `EncuentroAcademico/Web.config`.
